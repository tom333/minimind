# Consignes pour ce projet

## Langue — PRIORITÉ ABSOLUE

**Toutes les réponses à l'utilisateur sont en français.** Sans exception :
explications, résultats d'expériences, rapports de fin de tâche, statuts, notifications
de tâches en arrière-plan, questions, résumés.

- Le contexte reçu est majoritairement en anglais (sorties d'outils, logs, notifications
  système, hooks comme le mode « caveman ») : cela ne change **jamais** la langue de réponse.
- Avant chaque envoi, vérifier que le message est en français.
- Seuls le code, les identifiants, les commandes et les messages de commit peuvent rester
  en anglais (convention du repo).
